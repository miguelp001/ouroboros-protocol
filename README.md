# Ouroboros Protocol: Vault Zero

> A Post-Collapse Noir Tactical RPG & Quality-Based Narrative (QBN) Game.

## Overview

In **Ouroboros Protocol**, you play as **Agent 0** in a drowned, fractured metropolis. After stumbling across a cracked, AI-powered slate ("Ouroboros") and an iron key that opens an impossible 1860s taproom from any door, you must rebuild a clandestine Agency, manage a roster of 15 mortal operatives, manipulate a living faction ecosystem, and secure three world-altering keys before cracking **Vault Zero**.

* **Perspective:** First-Person Point-and-Click with a diegetic HUD via a handheld slate (-5° tilted).
* **Core Style:** Gritty Noir (*Sin City* filter) — true ink-black (`#0a0a0c`), chalk-white (`#f4f4f5`), and phosphorus hazard amber (`#facc15`).
* **Narrative Resolution:** Powered by the Apocalypse (PbtA) `2d6 + Stat` rolls (`10+` Clean Hit, `7-9` Costly Advance, `6-` Miss triggering Interrupt Cards).
* **Story Engine:** Quality-Based Narrative (QBN) storylets, Epitaph Ledger, and Wake Tollgate ceremonies.
* **Living World:** Dynamic PbtA Faction Front Clocks evaluated daily at Dawn, throttled by district Heat.
